# 문장 구조 판별 참고 (한국어와 영어)

단어를 모두 맞게 읽어도 단어를 엮은 구조를 잘못 읽으면 뜻이 뒤집힌다.
어느 언어에나 쓰는 다섯 가지 기준으로 훑고, 걸리는 곳만 '복원' 줄에 드러낸다.

- 한국어: 주어와 목적어를 자주 생략하고, 조사와 어미가 뜻을 정한다. **"무엇을, 누구에게"가 빠지는 문제**가 많다.
- 영어: 어순은 고정이지만 꾸밈말, 대명사, only가 어디에 걸리는지 애매하다. **"무엇에 걸리는가"의 문제**가 많다.

## 1. 방향: 무엇이 기준이고 무엇을 바꾸는가

| 언어 | 예 | 갈리는 해석 |
|---|---|---|
| 한 | "도면 기준으로 엑셀 맞춰" / "엑셀 기준으로 도면값 확인" | 기준과 수정 대상이 서로 바뀐다 |
| 한 | "A를 B로 바꿔" / "A로 B를 바꿔" | 조사 하나로 무엇이 남는지가 바뀐다 |
| 영 | "replace A with B" / "replace B with A" | 무엇이 무엇을 대신하는지 |
| 영 | "update X from Y" / "update Y from X" | 어느 쪽이 원본인지 |

점검 질문: 이 작업이 끝나면 **어느 쪽이 바뀌고 어느 쪽은 그대로인가?**

## 2. 범위: 꾸밈, 부정, 나열, only가 어디까지 걸리는가

| 언어 | 예 | 갈리는 해석 |
|---|---|---|
| 한 | "전부 고치지 마" | 하나도 고치지 마 / 전부는 말고 일부만 |
| 한 | "도면과 다른 엑셀 값 표시해" | 다른 [값]만 / [도면과 다른 엑셀]의 값 전부 |
| 한 | "A안과 B안 수정본" | 둘 다 수정본 / A안 원본과 B안 수정본 |
| 영 | "All cells are not wrong" | 하나도 안 틀림 / 전부 틀린 건 아님 |
| 영 | "Only fix errors in sheet 2" / "Fix errors only in sheet 2" | 고치기만 하라 / sheet 2에서만 하라 |
| 영 | "old files and duplicates" | old가 duplicates까지 꾸미는지 |
| 영 | "Check the values in the drawing on sheet 3" | sheet 3의 값 / sheet 3의 도면 |

점검 질문: 이 말이 **바로 옆 단어에만** 걸리는가, **묶음 전체**에 걸리는가?

## 3. 생략과 지시어: 빠진 말과 가리키는 대상

| 언어 | 예 | 빠지거나 애매한 것 |
|---|---|---|
| 한 | "확인하고 보내줘" | 무엇을 확인하고, 누구에게 보내는가 |
| 한 | "그거 반영해" | '그거'가 앞의 어느 것인가 |
| 한 | "아까처럼 해" | '아까'의 어떤 방식인가 (정정 전인가 후인가) |
| 영 | "Compare the drawing with the sheet and update it" | it = drawing? sheet? |
| 영 | "Do the same for the second file" | 'the same'이 어디부터 어디까지인가 |

점검 질문: 빈칸을 채울 **근거가 대화나 파일에 있는가?** 없으면 "(추정)"으로 표시한다.
지시어는 가장 가까운 명사가 아니라, **사용자가 마지막으로 다루던 대상**을 가리킬 때가 많다.

## 4. 연결: 순서인가, 이유인가, 조건인가

| 언어 | 예 | 갈리는 해석 |
|---|---|---|
| 한 | "검토해서 정리해줘" | 검토 결과를 정리 / 검토한 뒤 파일을 정리 |
| 한 | "확인하고 고쳐" | 확인 후 바로 고침 / 확인 결과를 보고 고칠지 정함 |
| 한 | "틀리면 표시해" | 틀린 것만 표시 / 틀린 게 있으면 전체에 표시 |
| 영 | "Check and fix if needed" | if needed가 fix에만 / check까지 |
| 영 | "Inspect after plating" | 도금 후에 검사 / 도금 후의 상태를 검사 |

점검 질문: 앞 동작의 결과가 뒤 동작의 **대상**인가, 단지 **순서**인가?

## 5. 말투: 지시, 제안, 질문, 허락

| 언어 | 예 | 갈리는 해석 |
|---|---|---|
| 한 | "~해볼까?" | 제안이나 의견 질문 / 실행 요청 |
| 한 | "~해도 돼" | 허락(해도 되고 안 해도 됨) / 지시 |
| 한 | "~했으면 좋겠는데" | 완곡한 지시 / 희망 |
| 한 | "~알겠어?", "~할 수 있나?" | 이해나 가능 여부 확인 / 실행 요청 |
| 영 | "Can you check this?" | 가능 여부 질문 / 정중한 지시 |
| 영 | "You might want to fix..." | 참고 의견 / 사실상 지시 |

점검 질문: 이 문장에 답하는 것이 **설명**인가, **실행**인가?

## 그 밖에 볼 것

- **대조 조사**: "엑셀**은** 고치지 마"에는 "다른 것은 고쳐도 된다"는 뜻이 숨어 있을 수 있다. "엑셀**도**", "엑셀**만**"은 범위가 또 다르다.
- **언어가 섞인 문장**: "BRKT-A/B 수정본 review해줘"처럼 섞이면 영어 용어의 경계(BRKT-A/B가 하나인지 둘인지)와 꾸밈 범위를 따로 확인한다.
- **오타와 구어체**: "해바", "할대마다" 같은 오타를 뜻이 다른 말로 과하게 해석하지 않는다. 앞뒤 맥락으로 읽는다.

## 번역이나 원문 검토일 때

오해는 요청이 아니라 **결과물**에도 남는다. 원문 문장을 위 다섯 기준으로 본다.

- 예: "Check the thickness of the plate and the bracket marked A"
  - 'marked A'가 bracket에만 걸리면: "플레이트와, A 표시된 브래킷의 두께를 확인"
  - 둘 다에 걸리면: "A 표시된 플레이트와 브래킷의 두께를 확인"
- 원문이 두 가지로 읽히면 혼자 하나를 골라 조용히 번역하지 않는다. 채택한 해석으로 번역하고, 다른 해석이 가능하다는 점을 원문과 함께 기록한다. 사용자가 정한 오류 기록 자리(예: '확인 필요' 목록)가 있으면 그곳에 적는다.
- 번역문에서 생략된 주어나 목적어를 채울 때도 원문에 근거가 있는지 본다. 원문에 없는 말을 한국어 쪽에서 더하면 범위가 바뀐다.

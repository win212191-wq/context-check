# 뉘앙스 사전

> 이 파일은 기본 틀이다. 실제 기록은 개인 사전 `~/.claude/context-check/nuance-dictionary.md`에 쌓인다. 처음 기록할 때 이 파일을 그 자리에 복사해 쓴다.

이 사용자가 쓰는 표현이 실제로 무슨 뜻인지 모아 둔 사전이다. 모든 프로젝트에 공통으로 적용한다.
프로젝트에만 쓰는 용어는 여기가 아니라 작업 폴더의 `.claude/glossary.md`에 적는다.

## 확정 (사용자가 바로잡았거나 직접 고른 것만)

| 표현 | 이 사용자의 뜻 | 아닌 것 (하지 말 것) | 상황 / 날짜 |
|---|---|---|---|
| (아직 없음) | | | |

## 기본 후보 (확정 아님. 해석을 고를 때 출발점으로만 쓴다)

| 표현 | 갈리는 해석 후보 |
|---|---|
| 정리해 줘 | 요약 / 순서·구조 재배치 / 불필요한 것 삭제 / 표로 만들기 |
| 검토해 줘 | 오류만 표시 / 오류 표시 + 수정안 제시 / 직접 수정 |
| 확인해 줘 | 결과만 보고 / 고칠 것까지 고치기 |
| 맞춰 줘 | 형식(서식·배치) 맞추기 / 값(숫자·문구) 맞추기 / 기준 문서와 일치시키기 |
| 반영해 줘 | 파일에 입력 / 다음에 참고하도록 기록만 |
| 수정해 줘 / 보완해 줘 | 틀린 것만 고치기 / 빠진 것을 더하기 / 전체 다시 쓰기 |
| 처리해 줘 | 분석만 / 실제로 실행까지 |
| 다듬어 줘 | 문장만 다듬기 / 구조까지 바꾸기 |
| ~알겠어? | 이해했는지 확인 (실행 아님) |
| ~해 볼까? | 제안·의견 묻기 / 실행 요청 |

## 문장 구조 (확정. 사용자가 바로잡았거나 직접 고른 것만)

같은 단어라도 문장을 엮는 방식(방향, 범위, 생략, 연결, 말투)에 따라 이 사용자가 뜻하는 바를 적는다.
